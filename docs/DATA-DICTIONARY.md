# 定义表 stockflow

## 文件与列

| 文件 | 列 | 类型 | 单位 | 可空 | 说明 |
|---|---|---|---|---|---|
| 流水 | 单据号 | 字符串 | — | 否 | 业务键之一，与行号组成唯一键 |
| 流水 | 行号 | 整数 ≥1 | — | 否 | 单据内行序号 |
| 流水 | 类型 | 枚举 | — | 否 | 采购入库 / 销售出库 / 生产领料 / 退货入库 / 调拨 / 盘点调整 |
| 流水 | 仓库 | 枚举 | — | 否 | WH-A / WH-B / WH-C |
| 流水 | 物料编码 | 字符串 | — | 否 | 前导零保形，不做数字转换 |
| 流水 | 数量 | 十进制，四位小数 | 见单位列 | 否 | 必须 > 0；出库方向由类型或方向列决定 |
| 流水 | 单位 | 枚举 | kg / g | 否 | g 按 0.001 折 kg |
| 流水 | 单价 | 十进制，四位小数 | 元/kg | 视类型 | 入库类必填，无原单退货必填，调整入必填 |
| 流水 | 发生时间 | 时间 | UTC 存储 | 否 | 带偏移先归一 UTC；裸时间按 +08:00；只给日期按当日 00:00 |
| 流水 | 方向 | 枚举 | 入 / 出 | 调拨与调整必填 | 其余类型方向由类型固定 |
| 流水 | 关联单号 | 字符串 | — | 是 | 退货填原出库单号；调拨两边填同一单据号 |
| 流水 | 版本 | 整数 ≥1 | — | 否 | 同一业务键的修订号，高版本覆盖低版本 |
| 期初 | 仓库 / 物料编码 / 数量 / 单位 / 单价 | 同上 | kg、元/kg | 否 | 数量为 0 不建层，只记标志 |
| 实盘 | 盘点单号 / 仓库 / 物料编码 / 实盘数量 / 单位 / 版本 | 同上 | kg | 否 | 同一盘点单同一物料同一仓库只取最高版本 |

## 数值与精度

- 数量、单价、金额一律 `Decimal`，禁止 float 累加。
- 数量量化到 0.0001 kg；单价量化到 0.0001 元/kg；金额保留精确乘积，展示与导出量化到 0.0001 元。
- 调拨入边层成本 = 出边实际消耗金额 ÷ 数量，量化到 0.0001。
- 对外 JSON 用字符串；CSV 用四位小数文本；大整数与编码不走数字类型。

## 时间

- 存储一律 UTC ISO 字符串；页面显示 `+08:00`。
- 裸时间按 `Asia/Shanghai` 解释；纯日期按当日 00:00 本地时间。
- 重放顺序用 UTC 时间比较，避免同一时刻落进两个顺序。

## 空值

- 空串、`-`、`--`、`/`、`N/A`、`NA`、`null`、`none`、`未知` 是空值哨兵，语义是「没有填」，不是 0。
- 数量命中哨兵进隔离（`QTY_MISSING`）；单价命中哨兵按类型判 `PRICE_REQUIRED`。
- 三态分开：0 是有效数字，空串是缺失，哨兵是登记过的缺失写法。

## 业务键与去重

- 去重键 = `(单据号, 行号)`，不是全行哈希：同一行修订只保留最高版本。
- 最高版本出现两个不同取值 → 整组隔离 `DUP_DOC_CONFLICT`；最高版本只有一种取值 → 保留文件里先出现的一行，其余同版本同值记重复。
- 低版本行记被取代，既不参与重放也不计入隔离统计。

## 基线与增量补丁

- 基线 = 当前生效的流水集合，按 `(单据号, 行号, 版本, 内容指纹)` 去重，随每个批次事务性更新；整批导入重置基线，补丁在基线上合并。
- 内容指纹 = 内部列名 → 原始单元格的 sha256，与文件列顺序无关。
- 基线携带两类行：无解析码的采信行（含旧版本与冲突对，参与版本裁决）；有解析码的隔离行（留在账上待解决，重建时按 cells 与标志位复原）。
- 补丁采信分类：
  - `added` 新增业务键；`upgraded` 更高版本覆盖（记被取代版本号）；
  - `conflict` 同版本不同取值 → 整组隔离，基线该键不更新；
  - `stale` 低于基线版本 → 记被取代，不改账；
  - `unchanged` 与基线同键同版本同指纹 → 不重复入账（幂等关键）；
  - `invalid` 补丁里的解析失败行 → 进隔离留证；
  - `resolved` 补丁里同业务键的可采信行修好了基线隔离行 → 旧隔离行移出基线。
- 合并集 = 基线携带行 + 采信的补丁行，按 canonical 全序排列；其 sha256 进 run_id，同一补丁重试得到同一批次。
- 改判单据 = 前后两个批次按单据号聚合 `(状态, 原因码)` 的差集；完全相同的重复行不参与比较。
- 补丁批次与整批导入共用同一条 质量 → 重放 → 成本 → 对账 链；落库单事务，中断即回滚到完整旧版。

## 层与成本

- FIFO 层：期初一层、每次入库一层、调拨入一层、盘点盘盈一层；层内数量只减不增（退货回原层除外）。
- 出库按层创建顺序消耗；在手不足时整行拒绝，不部分消耗、不压负库存。
- 退货带原单号：按原单消耗顺序把数量放回原层；无原单号：按本次单价建新层。
- 出库成本 = 消耗层金额之和 − 退货恢复金额（净成本）。

## 空态

- 0 行：`raw_rows = 0`，批次状态 `empty`。
- 仅表头：采信状态 `HEADER_ONLY`，同样 `empty`。
- 全空行：采信状态 `ALL_BLANK`，空行单独计数。
